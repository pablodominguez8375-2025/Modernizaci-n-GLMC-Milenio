# Database

Carpeta destinada al modelo de datos, migraciones, scripts, seed de desarrollo y documentación de PostgreSQL.

## Convenciones iniciales

- `schema/`: definición lógica del modelo.
- `migrations/`: migraciones versionadas.
- `seed/`: datos de prueba no sensibles.
- `docs/`: decisiones y diagramas de datos.

No almacenar credenciales, datos personales reales ni respaldos productivos en el repositorio.
