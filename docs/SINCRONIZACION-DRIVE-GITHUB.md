# Sincronización Drive / GitHub

La documentación funcional aprobada debe conservarse en ambos repositorios de trabajo:

- Google Drive: documentos oficiales y línea base funcional/documental.
- GitHub: consolidación versionada para desarrollo, QA, arquitectura y control de cambios.

Una modificación no debe considerarse consolidada hasta que su efecto funcional esté reflejado en ambos lugares.
