# PMGM-ROADMAP-001 — Roadmap v0.1

## Fase 0 — Gobierno y base técnica
- Consolidar documentación maestra.
- Definir arquitectura v0.1.
- Definir modelo conceptual de datos.
- Crear convenciones, ADRs y backlog.
- Preparar estrategia Git y CI/CD.

## Fase 1 — Fundaciones
- Identidad y SSO.
- Usuarios, roles y permisos.
- Miembros.
- Talleres / Logias.
- Auditoría base.
- Base PostgreSQL y migraciones.
- Dashboard inicial.

## Fase 2 — Núcleo administrativo
- Secretaría.
- Régimen Interior.
- Gestión Logial.
- Expediente digital.
- Tenidas, asistencia y excusas.
- Historial de cargos.
- Flujos solicitud → validación → revisión → autorización → resolución.

## Fase 3 — Servicios institucionales
- Documentos y biblioteca.
- Docencia.
- Tesorería.
- Hospitalaria.
- Calendario.
- Ceremonias.
- Comunicaciones y notificaciones.
- Reportes y memorias.

## Fase 4 — Integración y migración
- Inventario de sistemas actuales.
- Estrategia por sistema: Mantener / Integrar / Migrar / Reemplazar / Retirar.
- Integración con Joomla/CENDOC durante transición.
- Migración selectiva de datos y documentos.
- Conciliación de datos duplicados.
- Planes de rollback.

## Fase 5 — Evolución
- Aplicación / experiencia móvil.
- Nuevos servicios institucionales.
- Analítica y tableros avanzados.
- Automatización adicional.
- Integraciones externas.

## Criterio de avance
Cada fase se ejecutará mediante incrementos demostrables con criterios de aceptación, pruebas y documentación antes de promoción a `main`.
