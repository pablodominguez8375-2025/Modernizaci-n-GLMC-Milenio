# PMGM-REQ-022-ADD-001 — Extensión de validaciones para autorización de ceremonias

Este addendum complementa PMGM-REQ-022 y debe leerse junto con PMGM-REQ-025.

Antes de emitir una plancha definitiva para iniciación, aumento de salario o exaltación, Gran Secretaría deberá verificar como mínimo:

1. aprobación de Régimen Interior;
2. Taller al día con Gran Tesorería o excepción formal vigente;
3. Taller al día con reposiciones de Gran Hospitalaria o excepción formal vigente;
4. para iniciaciones, cumplimiento del plazo mínimo de publicación del insinuado configurado institucionalmente;
5. cualquier validación adicional vigente para ese tipo de ceremonia.

Gran Secretaría no recalcula saldos ni reposiciones. Consume la validación emitida por el área responsable y conserva la evidencia usada para autorizar.

Para iniciaciones, el plazo inicial de publicación se configura en 20 días, pero debe poder modificarse mediante configuración versionada sin alterar trámites históricos.

La autorización definitiva deberá bloquearse si cualquiera de estas condiciones obligatorias no se encuentra en un estado habilitante.
