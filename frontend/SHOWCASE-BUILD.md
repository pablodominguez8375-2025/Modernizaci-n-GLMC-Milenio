# Proyecto Centenario — Showcase GitHub Pages

Este archivo documenta la regeneración coordinada del Showcase público y del paquete instalable Pre-UAT.

- Fuente: rama `dev`.
- Demo: GitHub Pages con datos exclusivamente ficticios y `VITE_USE_MOCKS=true`.
- Paquete: workflow `Proyecto Centenario Pre-UAT Installable` construido desde el mismo estado de `dev`.
- La demo no usa autenticación OIDC real, API institucional, PostgreSQL, MinIO ni datos personales reales.
- La promoción a `main` continúa bloqueada hasta completar UAT funcional.

La cabecera de la demo expone el SHA corto del build, permitiendo verificar que la presentación corresponde al commit publicado.
